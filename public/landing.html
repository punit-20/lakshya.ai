Meet Your Autonomous Agents

Six specialized AI agents working in parallel — scraping, qualifying, emailing, messaging, posting, and optimizing 24/7.

🕵️

LeadHunter Agent

Autonomously crawls Reddit, Twitter, and LinkedIn using keyword campaigns. Scrapes posts via RSS feeds, DuckDuckGo indices, and live APIs. Qualifies leads with Gemini NLP scoring (0–100 intent score).

📧

Email Agent

Generates personalized cold pitch emails using Gemini AI with configurable tone (Professional, Casual, Aggressive). Dispatches through SMTP with full logging to the email_logs database. Tracks delivery status.

💬

WhatsApp Agent

Sends targeted outreach via the Meta Business WhatsApp API. Validates phone numbers, structures API packets, logs delivery status. Links to project-specific leads for personalized messaging sequences.

💼

LinkedIn Agent

Acquires proxy session tokens, visits target profiles, performs automated connection requests. Sends InMail pitches with personalized copy. Logs all LinkedIn engagement activity and tracks acceptance rates.

🎨

AdCreative Agent

Uses headless Chrome (Selenium) to search and download ad creative images from Lexica. Queues image generation tasks via the Python worker daemon with automatic retry logic (max 3 attempts). Auto-posts to social platforms.

🔍

SEO Agent

Performs technical SEO audits on target domains, analyzes page speed metrics, generates optimization blueprints. Creates keyword-rich blog post outlines and meta tag suggestions for organic reach growth.
